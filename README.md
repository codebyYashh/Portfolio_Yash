# Yash Agrawal Portfolio

## Run locally
1. Install Node.js (LTS).
2. Open this folder in VS Code.
3. Open the terminal in the project folder.
4. Run:

```bash
npm install
npm run dev
```

5. Open the local URL printed by Vite (usually http://localhost:5173).

## Build for deployment
```bash
npm run build
npm run preview
```
The production site is generated in `dist/`.

## Personalise before publishing
- Replace `public/profile.jpg` with Yash's approved portrait.
- Add `public/resume.pdf`.
- Update email, LinkedIn, GitHub and LeetCode URLs in `src/data.js`.
- Replace sample projects with real projects and working repository/demo URLs.
- Verify experience descriptions and dates in `src/data.js`.
- Remove any technology from the skills list that Yash cannot confidently discuss.

This is a frontend-only React + Vite site. No backend or database is required.
